# AirWin 🎧

**AirWin** — утилита для Windows, которая переносит фирменный опыт управления наушниками **Apple AirPods** с macOS на операционную систему Windows 10 / 11.

---

## ✨ Основные возможности

* **🍎 macOS Big Sur / Sonoma дизайн**:
  * Всплывающая анимированная карточка при открытии кейса наушников рядом с компьютером (с плавным выездом и исчезновением).
  * Компактный и эстетичный Центр управления (Control Center) по клику на иконку в трее.
* **🔋 Точный мониторинг аккумулятора**:
  * Раздельный заряд левого и правого наушника с индикацией зарядки ⚡ и нахождения в ухе 👂.
  * Заряд зарядного кейса.
  * Динамический бейдж с процентом заряда прямо на иконке в системном трее Windows.
* **🔇 Управление режимами шума (ANC)**:
  * Быстрое переключение между режимами: **Шумоподавление (ANC)**, **Прозрачность** и **Выкл**.
* **👂 In-Ear Detection (Автопауза)**:
  * Автоматическая приостановка музыки или видео при извлечении наушника из уха и продолжение воспроизведения при возвращении.
* **🎵 Фикс качества звука в Windows (Hands-Free Fix)**:
  * Решение проблемы ухудшения качества звука (переход в глухое 8 кГц моно при звонках или играх) путем отключения низкокачественного профиля Hands-Free Telephony в один клик.
* **🚀 Автозапуск вместе с Windows**:
  * Простая интеграция в реестр Windows для запуска в фоновом режиме без лишних окон.
* **🧪 Режим демонстрации (Demo Mode)**:
  * Позволяет протестировать весь интерфейс и анимации даже без подключенных AirPods.

## 🚀 Установка и запуск

### Требования
* Windows 10 / 11 (или macOS / Linux для разработки)
* Bluetooth 4.0+ с поддержкой Bluetooth Low Energy (BLE)
* Python 3.10+

### Установка зависимостей

```bash
git clone https://github.com/your-username/airwin.git
cd airwin
python -m venv .venv

# Для Windows:
.venv\Scripts\activate
pip install -r requirements.txt
```

### Запуск

```bash
# Обычный запуск (слушает BLE-эфир AirPods):
python -m airwin.main

# Запуск в режиме демонстрации (симуляция):
python -m airwin.main --demo

# Запуск с указанием конкретного MAC-адреса ваших AirPods:
python -m airwin.main --mac "XX:XX:XX:XX:XX:XX"
```

## 📦 Сборка автономного AirWin.exe (PyInstaller)

Для сборки одного исполняемого файла, который не требует установленного Python на компьютере пользователя:

```bash
pip install -r requirements-windows.txt
python build_exe.py
```

Готовый файл будет находиться в директории `dist/AirWin/AirWin.exe`.

## ⚙️ Структура проекта

```text
airwin/
├── airwin/
│   ├── core/
│   │   ├── airpods_parser.py    # Декодер BLE-пакетов Apple Continuity (0x004C, 0x07)
│   │   ├── ble_scanner.py       # Фоновый асинхронный сканнер Bleak
│   │   ├── device_manager.py    # Менеджер состояний, автопаузы и симуляции
│   │   ├── models.py            # Модели данных (AirPodsState, AirPodsModel, ANC)
│   │   └── windows_audio.py     # Управление воспроизведением и фикс Hands-Free
│   ├── ui/
│   │   ├── components.py        # Кастомные виджеты (карточки батареи, пилюли ANC)
│   │   ├── control_center.py    # Центр управления в стиле macOS Big Sur
│   │   ├── popup_card.py        # Анимированная всплывающая карточка
│   │   ├── qt_compat.py         # Совместимость с PySide6 и PyQt6
│   │   ├── styles.py            # Темная тема macOS Sonoma / Big Sur QSS
│   │   └── tray_icon.py         # Иконка системного трея с бейджем %
│   ├── utils/
│   │   └── autostart.py         # Настройка автозапуска в реестре Windows
│   ├── config.py                # Конфигурация и сохранение настроек JSON
│   └── main.py                  # Главная точка входа приложения
├── tests/
│   └── test_parser.py           # Модульные тесты парсера пакетов
├── build_exe.py                 # Скрипт сборки Windows .exe
├── requirements.txt             # Список зависимостей
└── README.md                    # Документация проекта
```
